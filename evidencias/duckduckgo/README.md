# DuckDuckGo — evidências conferidas

Oito pastas contêm os registros finais e os arquivos reais recebidos. [RESULTADOS.md](RESULTADOS.md) substitui as conclusões condicionais dos relatos anteriores. [INDEX.md](../INDEX.md) preserva nomes brutos, identificações e confiança.

Os JSON DDG da extensão são v0.4.0; js-leaks foi fotografado na etapa posterior, mas seu único resultado não identifica a condição com/sem plugin. Dois painéis query ficam em `query-parameters/pendentes/`. A repetição bounce com IDs iguais não está integralmente comprovada por dois pares completos. Não foram geradas novas capturas ou resultados DDG nesta finalização.
