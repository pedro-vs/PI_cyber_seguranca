# Evidências locais da Etapa 1

Dados reais de uma fixture controlada executada no Firefox 156.0.1, via `tests/firefox_smoke.py`. Ver ambiente, limites e tabela de resultados em `docs/VALIDACAO_ETAPA_1.md`.

Estes arquivos não substituem DDG, HARs dos três sites, Blacklight ou uBlock. Os screenshots do relatório mostram a página interna da própria extensão, aberta em aba para inspeção automatizada.

Para a validação no seu computador, adicionar `etapa1-popup-aluno.png`, `etapa1-storage-aluno.png`, o JSON exportado e a versão do Firefox. Não sobrescrever as evidências de outra execução.
