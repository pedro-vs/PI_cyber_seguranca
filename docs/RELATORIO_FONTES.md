## Leitura do manifesto

sha256 é o hash do arquivo bruto antes de movimentar; storedSha256 é o hash do artefato no repositório. Para E51, comparar sha256 ao HAR descomprimido. Para PNG/JSON/HAR sem gzip, os dois hashes coincidem. Identidade de execução usa URL, requestId e horários internos quando disponíveis, sem equiparar apenas pela ordem do nome do arquivo.
